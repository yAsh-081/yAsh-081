## 🧭 About Me

Hi, I am a Computing Science student at Simon Fraser University. I enjoy building software from the ground up, ranging from low-level internals to complete applications. My recent work includes native crash reporting in C, asynchronous networking, transactional backends, and machine learning.

- 🔭 Currently working on: **Extending [CrashVault](https://github.com/Yash-081/CrashVault) into a distributed crash-reporting system for collecting and correlating native failures across machines.**
- 🌱 Learning: Advanced AI/ML algorithms and computer vision techniques
- 🤝 Looking to collaborate on: **A vulnerability variant discovery engine that derives semantic signatures from disclosed vulnerabilities and searches codebases for previously unknown variants.**
- 🎯 2026 Goals: Read 52 research papers and turn more of what I learn into working software (28 papers read so far this year)
- ⚡ Fun fact: I can optimize your code faster than I can optimize my sleep schedule
